⚙️ About the System

PlateVision AI

An edge-accelerated, real-time Automatic Number Plate Recognition (ANPR) pipeline combining YOLO11x neural object detection with EasyOCR optical character recognition on NVIDIA CUDA.

Purpose

PlateVision was engineered to provide high-speed, local-first license plate detection and text extraction without reliance on third-party cloud APIs, monthly subscriptions, or expensive proprietary ANPR cameras. By pairing state-of-the-art vision models with an NVIDIA GeForce RTX 3050 GPU, PlateVision delivers sub-50ms inference times directly on the edge.

Technology Stack

Open-source frameworks and libraries powering the recognition engine.

Vision Model

Ultralytics YOLO11x

The latest iteration of the YOLO architecture, trained specifically on high-density vehicle plate datasets for sub-millisecond bounding box localization.

OCR Engine

EasyOCR (CRNN)

Optical character recognition for extracting plate numbers from detected regions.

GPU Acceleration

PyTorch with CUDA 12.6

Direct NVIDIA CUDA tensor computation enabling FP16 inference, high-throughput parallel batching, and consistent 25–35 FPS processing rates.

Vision Library

OpenCV (cv2)

Camera capture, image processing, and video annotation.

Backend Server

Flask (Python 3.10+)

Lightweight web server serving MJPEG multipart video streams, REST API endpoints, and handling thread-safe camera hardware locking.

Frontend

Modern Web UI

Pure modern CSS Grid, Flexbox, clean light styling, and async Fetch API client logic.
